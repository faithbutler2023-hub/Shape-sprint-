A short visual challenge

Shape Sprint

Complete a quick visual matching challenge. Remember the target shape, then decide whether each shape shown matches it.

How to play
Choose MATCH if the shape is the same as the target, or NO MATCH if it is different. Respond as accurately and quickly as you comfortably can.

Your participant code will be created automatically. You do not need to enter one.

Use the same device and browser for both rounds. Do not clear browser data between rounds.
